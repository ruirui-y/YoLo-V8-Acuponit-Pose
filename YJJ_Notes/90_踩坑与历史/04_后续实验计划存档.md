# 3. 下一阶段核心目标

优先寻找以下类型的 RGB-D 优势：

```text
1. RGB 视觉退化时的鲁棒性优势
2. 特定距离区间的优势
3. 检测 Recall / mAP50 的优势
4. 不同 Subject 上可重复的优势
5. Depth 被破坏后性能显著下降，证明优势来自 Depth
```

其中第一优先级：

> RGB Degradation Robustness

原因是它最符合 RGB-D 多模态输入的直觉：

```text
RGB 信息变差
      ↓
RGB 模型缺少可靠视觉特征

RGB-D：
RGB 变差
+
Depth 仍保留空间信息
      ↓
可能表现出更小的性能下降
```

# 4. 实验 A：Brightness Robustness

不重新训练。

使用完全相同的 test set 和模型权重。

对 RGB 部分施加固定亮度衰减：

```text
1.00
0.75
0.50
0.25
```

其中：

```text
1.00 = 原始图像
```

RGB 模型输入：

```text
Brightness-Degraded RGB
```

RGB-D 模型输入：

```text
同样退化后的 RGB
+
原始真实 Depth
```

注意：

> RGB-D 的前三通道必须和 RGB 模型看到的 RGB 完全一致。

否则比较不公平。

第一阶段不需要一次做十几种干扰。

先完成：


```text

```

```text

```

# 9. Performance Drop

除了直接比较 RGB 与 RGB-D 的最终指标，还应计算：

```text
Drop = Clean Score - Degraded Score
```

例如：

```text
RGB clean Pose      = 0.7608
RGB dark Pose       = 0.3000
RGB drop            = 0.4608

RGBD clean Pose     = 0.6868
RGBD dark Pose      = 0.5500
RGBD drop           = 0.1368
```

即使 clean 时：

```text
RGB > RGB-D
```

如果：

```text
RGBD drop << RGB drop
```

仍然可以形成明确结论：

> RGB-D 在 RGB 视觉退化条件下表现出更强的鲁棒性。

---

# 10. Robustness Curve

每种退化都画两条曲线：

```text
X 轴：退化强度
Y 轴：mAP / Recall

RGB
RGB-D
```

理想情况：

```text
Clean
RGB  较高
RGBD 略低或接近

退化增强
RGB 快速下降
RGBD 下降更慢

某个强度后
RGBD > RGB
```

这比只看一个 clean test mAP 更容易解释多模态输入的价值。

---

# 11. Robustness AUC

可以进一步计算整条退化曲线的面积：

```text
Robustness AUC
```

用于衡量：

> 模型在整个退化范围内的整体稳定程度。

如果：

```text
RGBD Robustness AUC > RGB Robustness AUC
```

则可以写：

> RGB-D 在视觉质量下降过程中具有更好的整体鲁棒性。

AUC 应作为辅助指标，不替代原始 mAP / Recall 曲线。

# 14. 实验 D：Distance Stratification

第二优先级。

利用 Depth NPY 中的真实距离，把 test 按手部区域平均 / 中位深度划分：

```text
Near
Mid
Far
```

要求：

- 分组阈值在看结果前确定；
- RGB 和 RGB-D 使用完全相同样本；
- 不因结果重新移动图片。

结果表：

| Distance | RGB Box | RGB-D Box | RGB Pose | RGB-D Pose |
|---|---:|---:|---:|---:|
| Near | ... | ... | ... | ... |
| Mid | ... | ... | ... | ... |
| Far | ... | ... | ... | ... |

目标不是预设：

```text
Far 一定 RGB-D 更强
```

而是验证：

> Depth 的价值是否随真实距离变化。

# 15. 实验 E：Multi-subject

当前 Cross-subject 只有一个 external Subject。



# 16. 实验 F：Cross-subject Depth Ablation

在后续正确的 Cross-subject benchmark 上重复：

```text
True Depth
Zero Depth
Cross-image Shuffle

```

```text
True vs Zero
```

如果多个 Subject 上：

```text
True > Zero
```

则能进一步说明：

> RGB-D 在泛化条件下仍然真实利用 Depth。

# 17. 成功标准

本项目不要求：

```text
RGB-D 所有指标全部高于 RGB
```

满足以下任意一种稳定结果，就可以构成 RGB-D 优势章节：

### 场景 1

多个 RGB 退化等级中：

```text
RGBD Pose / Box 下降明显更慢
```

### 场景 2

Robustness AUC：

```text
RGBD > RGB
```

### 场景 3

特定距离分层：

```text
RGBD > RGB
```

并在多个 Subject 上重复。

### 场景 4

多个 Subject 的：

```text
Box Recall
或
Box mAP50
```

RGB-D 持续高于 RGB。

### 场景 5

RGB 退化后：

```text
RGB prediction 明显失效
RGBD prediction 仍保持稳定
```

且能够通过定量结果与逐图可视化共同证明。

# 18. 不允许的做法

为了保证最后论文可以放心使用结果，禁止：

```text
看完结果以后临时选择最有利的退化等级
```

禁止：

```text
RGB 与 RGB-D 使用不同 test 样本
```

禁止：

```text
只展示 RGB-D 成功案例，不展示失败案例
```

禁止：

```text
为了让 RGB-D 获胜临时调整模型评估阈值
```

禁止：

```text
因为某 Subject 对 RGB-D 不利就删除该 Subject
```

所有实验条件应当在正式批量测试前固定。

# 19. 推荐最终论文故事线

可以形成：

```text
Baseline
    ↓
RGB / RGB-D 正常条件比较

Depth Ablation
    ↓
证明第四通道真实参与预测

Cross-subject
    ↓
说明未知 Subject 是更困难的泛化场景

RGB Degradation Robustness
    ↓
展示 RGB-D 在视觉退化环境下的互补优势

Distance Stratification
    ↓
分析真实深度距离与性能之间的关系

Multi-subject
    ↓
验证优势能否跨受试者重复
```

最终结论可以写成：

> RGB-D 并非在所有标准测试指标上都优于 RGB，但深度信息被模型真实利用，并能够在视觉退化、检测召回或特定空间条件下提供额外的鲁棒性与互补信息。
