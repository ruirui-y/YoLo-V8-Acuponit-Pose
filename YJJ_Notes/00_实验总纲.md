# YJJ Pose 实验总纲

## 1. 当前研究任务

当前项目研究手部穴位 Pose 检测，标注 7 个关键点（K0 ~ K6）。

现阶段实验只保留三个主方向：

1. **RGB 与 RGBD 对比**
2. **不同网络模型对比**
3. **不同 YOLO 版本统一改成 4 通道后的对比**

旧的腹部、腿部、580 张混合数据等实验只作为历史资料，不再作为当前 Hand 主实验结论。

---

## 2. 三个实验方向

### 方向 1：RGB vs RGBD

状态：**阶段性完成**

当前正式对比：

- RGB：3 通道
- RGBD：4 通道，第 4 通道为经过修补和滤波后的 Depth
- 正式泛化测试：Cross-subject，101 张，测试人与训练人不同
- 当前模型：
  - RGB：`runs/pose/train_pose_rgb_3ch5/weights/best.pt`
  - RGBD：`runs/pose/train_pose_rgbd_4ch5/weights/best.pt`

最新 Cross-subject 结果：

- Total：101
- RGB matched：66 / 101
- RGBD matched：101 / 101
- Common matched：66
- RGB NME：0.088657
- RGBD NME：0.059819
- Delta：-0.028838
- RGBD wins：63 / 66
- RGB wins：3 / 66

单关键点中，整体最稳定的 RGBD 改善集中在 K1、K3、K5。

本方向当前不再继续扩展 Brightness、Blur、Distance 等额外实验。论文或答辩后期如果确实缺证据，再回头补。

---

### 方向 2：不同网络模型对比

状态：**下一阶段**

目标：

在输入模态、数据集、训练条件和评价指标保持一致的条件下，只改变网络模型，比较不同网络结构对 Hand Pose 的影响。

原则：

- 优先统一使用当前有效的 4 通道 RGBD 数据管线。
- Train / Val / Cross-subject Test 必须完全一致。
- Depth 预处理必须一致。
- 训练超参数尽量一致。
- 不把“YOLO 版本变化”混进本方向；YOLO 版本单独放到方向 3。

具体候选模型尚未最终确定，确定后填写到 `02_不同网络模型对比/00_实验设计.md`。

---

### 方向 3：YOLO 版本 4 通道对比

状态：**待进行**

目标：

将不同 YOLO Pose 版本按同一规则改造成 4 通道 RGBD 输入，在相同数据、相同 Depth 管线和尽可能一致的训练条件下比较。

核心要求：

- 所有版本都使用相同的 RGBD 数据。
- 第 4 通道初始化规则统一。
- 同级模型规模尽量对应比较，例如 n 对 n、s 对 s。
- 不把不同规模造成的收益误认为版本收益。

## 3. 当前正式评价体系

主评价分为两类。

### 3.1 覆盖能力

通过 bbox IoU 匹配统计：

- Total
- RGB / 模型 matched
- Common matched
- model-only
- neither

当前默认成功匹配阈值：

`bbox IoU >= 0.50`

覆盖率必须与定位误差一起报告。

### 3.2 关键点定位能力

主指标：NME。

单关键点像素误差：

`sqrt((x_pred - x_gt)^2 + (y_pred - y_gt)^2)`

NME 分母：

`GT bbox diagonal = sqrt(w_gt^2 + h_gt^2)`

只统计 `visibility > 0` 的 GT keypoint。

RGB / RGBD 总体定位比较只在 Common matched 集合上进行。

## 4. 实验有效性原则

以下规则以后所有方向统一遵守：

- Stable ID 不等于 Semantic ID，关键点语义必须先审计。
- Cross-subject 才作为正式泛化证据；同主体连续帧只能作为 sanity check。
- RGB 与 RGBD 必须使用完全对应的样本和标签。
- Depth 训练和测试预处理必须一致。
- 不允许把旧错误标签结果与当前结果混在同一张“最终表”里。
- CSV 用于全量统计，但典型案例必须结合绝对误差、bbox 和可视化人工检查。
- “RGBD 比 RGB 好”和“网络确实使用了 Depth”是两个不同问题。
- 任何改动如果同时改变了多个变量，不能直接把性能变化全部归因于其中一个变量。
