- 同一 NME 定义

## 6. 主评价指标

### 6.1 Cross-subject coverage

必须记录：

- Total
- Matched
- Match rate

如果是两模型逐图比较，再记录 Common matched。

### 6.2 NME

使用与方向 1 完全一致的定义：

- GT bbox diagonal 归一化
- visibility > 0
- bbox IoU >= 0.50 才算 matched

### 6.3 单关键点像素误差

记录：

- K0 ~ K6 mean px
- median px
- 每个 K 的胜负数量

### 6.4 标准 Pose 指标

如果模型框架支持，统一记录：

- Box mAP50
- Box mAP50-95
- Pose mAP50
- Pose mAP50-95

### 6.5 效率

在需要比较部署价值时再记录：

- Params
- FLOPs
- 推理时间 / FPS
- 显存占用

---

## 7. 结果判定原则

不能只看一项 mAP。

优先顺序：

1. Cross-subject 是否稳定 matched
2. Common / 全有效样本 NME
3. K0~K6 是否存在结构性弱点
4. Pose mAP
5. 参数量与速度

如果一个模型 mAP 高，但 Cross-subject NME 或 coverage 明显更差，不能直接判定它更适合当前任务。
