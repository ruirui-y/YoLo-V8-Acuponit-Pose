## 8. Depth 第四通道映射

当前 Depth 映射范围：

- low：1100 mm
- high：1850 mm

无效 Depth 统一考虑：

- 非有限值
- `depth <= 0`
- `depth == 65535`

映射公式：

```text
ch4 = 1 + (clip(depth, 1100, 1850) - 1100) * 254 / 750
```

有效深度映射到约 1~255。

当前正式 RGBD 数据使用修补后的 `out_npy_filtered` 生成。

## 10. 当前 NME 评估规则

脚本：

`YJJ_Pose_Scripts\04_eval\eval_rgb_vs_rgbd_nme.py`

关键规则：

- GT keypoint 有效条件：`visibility > 0`
- GT / pred 坐标使用浮点计算
- 预测目标通过最高 bbox IoU 与 GT 匹配
- 成功匹配阈值：`IoU >= 0.50`
- 推理 `conf = 0.001`
- NME 分母：GT bbox diagonal
- RGB vs RGBD NME 总体比较只统计 Common matched
- 匹配数量单独作为 coverage 指标报告

NME：

```text
d_k = sqrt((x_pred - x_gt)^2 + (y_pred - y_gt)^2)
s   = sqrt(w_gt^2 + h_gt^2)
e_k = d_k / s
NME = mean(e_k)
```

## 11. Same-subject Test 的定位

训练数据中的 12 张 test 与训练数据来自同一主体且时间连续。

它可以用于：

- sanity check
- 管线检查
- 基础消融
