# 腹部穴位 RGBD 关键点检测实验方案

## 一、实验概述

### 1.1 研究目标
本实验旨在验证两个核心假设：
- **假设一**：深度通道（Depth）的加入能提升腹部穴位关键点检测的精度
- **假设二**：不同骨干网络在 4 通道 RGBD 输入下的性能存在差异，需选取最优方案

### 1.2 数据集
- **数据集名称**：自建腹部穴位 RGBD 数据集（Acupoint Dataset）
- **图像格式**：4 通道 PNG（RGBA，A 通道为深度信息）
- **标注格式**：YOLO Pose 格式（腹部大框 + 3 个关键点）
- **数据集划分**：训练集 ？张 / 验证集 ？张 / 测试集 ？张

## 二、实验组设计

### 方向一：输入模态消融实验（RGB vs RGBD）

**目的**：验证深度通道的有效性

| 实验组     | 模型         | 输入通道    | 预训练权重来源                               |
| ---------- | ------------ | ----------- | -------------------------------------------- |
| A1（基线） | YOLOv8n-Pose | 3（RGB 仅） | 官方 `yolov8n-pose.pt` → 保留原 3 通道       |
| A2（本文） | YOLOv8n-Pose | 4（RGBD）   | `build_rgbd_pose_weights.py` 转换的 4 通道权重 |

**控制变量**：所有训练超参数完全一致，仅输入通道数不同。

---

### 方向二：骨干网络对比实验（全部 4 通道 RGBD）

**目的**：比较不同骨干网络在 RGBD 输入下的性能

| 实验组     | 模型                      | 参数量 | Pose 支持 | 预训练权重来源     |
| ---------- | ------------------------- | ------ | --------- | ------------------ |
| B1（基线） | YOLOv8n-Pose              | ~3.3M  | ✅ 原生    | 官方 → 转 4 通道   |
| B2         | YOLOv8s-Pose              | ~11.2M | ✅ 原生    | 官方 → 转 4 通道   |
| B3         | YOLO11n-Pose              | ~2.9M  | ✅ 原生    | 官方 → 转 4 通道   |
| B4         | YOLO11s-Pose              | ~9.8M  | ✅ 原生    | 官方 → 转 4 通道   |
| B5（可选） | RT-DETR-L（如有 Pose 版） | ~32M   | ⚠️ 需确认  | 官方 → 适配 4 通道 |

**控制变量**：所有模型均使用 4 通道 RGBD 输入，训练超参数统一。

**骨干网络特点说明**：

| 模型         | 骨干网络                            | 特点                           |
| ------------ | ----------------------------------- | ------------------------------ |
| YOLOv8n-pose | CSPDarknet + FPN/PAN                | 轻量高效，成熟稳定             |
| YOLOv8s-pose | CSPDarknet + FPN/PAN（加宽加深）    | v8n 的放大版本，精度更高       |
| YOLO11n-pose | 改进 CSPNet + 优化 Neck             | Ultralytics 最新架构，更优效率 |
| YOLO11s-pose | 改进 CSPNet + 优化 Neck（加宽加深） | 11n 的放大版本                 |

## 三、评价指标

### 3.1 目标检测指标（腹部大框）

| 指标         | 说明                                           |
| ------------ | ---------------------------------------------- |
| Box mAP50    | 框的 IoU 阈值 0.5 时的平均精度                 |
| Box mAP50-95 | 框的 IoU 阈值 0.5~0.95 的平均精度（步长 0.05） |
| Precision    | 精确率                                         |
| Recall       | 召回率                                         |

### 3.2 关键点检测指标

| 指标               | 说明                                       |
| ------------------ | ------------------------------------------ |
| Pose mAP50         | 关键点 OKS 阈值 0.5 时的平均精度           |
| Pose mAP50-95      | 关键点的综合平均精度                       |
| 关键点平均像素误差 | 预测点与标注点的欧氏距离平均值（单位：px） |
| 单个关键点像素误差 | 左穴位 / 肚脐 / 右穴位 各自的平均误差      |
| PCK（可选）        | 关键点正确估计比例                         |

### 3.3 效率指标

| 指标             | 说明            |
| ---------------- | --------------- |
| 参数量（Params） | 模型大小（M）   |
| 计算量（FLOPs）  | 浮点运算数（G） |
| 推理速度（FPS）  | 每秒处理帧数    |

## 六、预期结论

1. **方向一**：4 通道 RGBD 在 Pose mAP50 和关键点误差上应显著优于 3 通道 RGB，尤其在有光照变化或腹部姿态差异较大的样本上优势更明显。
2. **方向二**：
   - YOLO11 系列在同等参数量下略优于 YOLOv8 系列（架构更新）
   - YOLOv8s/YOLO11s 以约 3 倍参数量换取了一定的精度提升
   - 最终推荐 YOLOv8n-Pose 4ch 或 YOLO11n-Pose 4ch（精度与效率的最佳平衡）
3. **消融实验亮点**：第 4 通道（深度）的贡献可以量化为精度提升的具体百分点，作为论文的核心创新证据。
