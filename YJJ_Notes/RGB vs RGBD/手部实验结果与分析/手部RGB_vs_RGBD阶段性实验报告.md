# 手部 RGB vs RGBD 阶段性实验报告

> 状态：阶段性记录，当前用于梳理事实与后续实验方向，不作为论文最终结论。  
> 实验对象：Hand 单一部位 YOLOv8 Pose，RGB 3 通道 vs RGBD 4 通道。

---

## 1. 当前实验要回答的两个问题

本轮实验实际上包含两个不同的问题，后续分析必须分开：

### 问题 A：RGBD 最终性能是否高于 RGB？

即比较两个独立训练模型在同一 test 集上的最终指标：

- RGB 模型：3 通道输入；
- RGBD 模型：4 通道输入；
- 两者使用同一批数据划分；
- test 集完全独立于训练和验证。

### 问题 B：RGBD 模型是否真的使用了 Depth 第四通道？

即保持已经训练好的 RGBD 模型完全不变，只修改测试阶段的第 4 通道，观察性能是否变化。

这两个问题不能混为一谈：

> “模型使用了 Depth”不等于“RGBD 的最终 mAP 一定高于 RGB”。

---

## 2. Hand 数据集与测试集

当前 Hand 数据集：

- 总样本数：81
- train：57
- val：12
- test：12
- 关键点数量：7
- `kpt_shape = [7, 3]`
- RGB 与 RGBD 使用完全相同的样本划分
- test 为独立测试集

当前 test 只有 12 张，因此所有 test 指标都需要注意小样本波动问题。

## 4. 为什么继续做 Depth 消融

正式 test 只能回答“RGBD 有没有赢 RGB”，却不能回答：

> RGBD 模型训练完成后，到底有没有真正使用第 4 通道？

因此后续保持以下条件全部不变：

- 不重新训练；
- 不修改 RGBD `best.pt`；
- 同一批 12 张 test；
- 同一份 labels；
- 同一 imgsz；
- 同一 batch；
- `split=test`；
- 仅修改第 4 通道 Depth。

---

## 5. Depth 消融实验

当前已经实际完成 4 种输入条件：

1. `true_depth`
2. `zero_depth`
3. `shuffled_depth`
4. `spatial_shuffle_depth`

### 5.1 True Depth

正常的 RGB + 正确 Depth。

| 指标 | 数值 |
|---|---:|
| Box mAP50-95 | 0.9270 |
| Pose mAP50-95 | 0.8865 |

这是 RGBD 模型的正常 test 基线。

---

### 5.2 Zero Depth

RGB 三通道保持不变，第 4 通道全部置 0。

| 指标 | 数值 |
|---|---:|
| Box mAP50-95 | 0.9010 |
| Pose mAP50-95 | 0.8563 |

相对于 True Depth：

| 指标 | True - Zero |
|---|---:|
| Box mAP50-95 | +0.0260 |
| Pose mAP50-95 | +0.0302 |

当前可以说明：

> RGBD 模型对第 4 通道存在依赖或敏感性。

但不能仅凭这一组就断言“这 3% 完全来自有效深度几何信息”，因为全 0 通道本身也是明显偏离训练分布的输入。

---

### 5.3 Cross-image Shuffled Depth

保持当前图片 RGB 不变，但第 4 通道换成其他 test 图片的 Depth。

| 指标 | 数值 |
|---|---:|
| Box mAP50-95 | 0.9324 |
| Pose mAP50-95 | 0.8865 |

相对于 True Depth：

| 指标 | True - Cross-image Shuffle |
|---|---:|
| Box mAP50-95 | -0.0054 |
| Pose mAP50-95 | 0.0000 |

现象：

> 换成另一张图片的 Depth 后，Pose 指标几乎没有变化。

这个结果不能单独解释成“模型没有利用 Depth”，因为后续检查发现同一采集序列中的 Depth 帧整体仍具有较高相似性。

---

### 5.4 Spatial Shuffle Depth

这一组不使用其他图片的 Depth。

做法是：

- RGB 完全不变；
- 使用当前图片自己的 Depth 数值；
- Depth 像素值集合不变；
- 只随机打乱 Depth 像素在空间中的位置；
- 因此 min / max / mean / std / histogram 保持一致；
- 但 Depth 的空间结构与 RGB-Depth 像素对应关系被彻底破坏。

实际结果：

| 指标 | 数值 |
|---|---:|
| Box P | 0.6000 |
| Box R | 1.0000 |
| Box mAP50 | 0.9888 |
| Box mAP50-95 | 0.2920 |
| Pose P | 0.1000 |
| Pose R | 0.1667 |
| Pose mAP50 | 0.0786 |
| Pose mAP50-95 | 0.0079 |

Pose mAP50-95：

- True Depth：0.8865
- Spatial Shuffle：0.0079

性能几乎完全崩溃。

---

## 6. 四组 Depth 消融汇总

| 输入方式 | Box mAP50-95 | Pose mAP50-95 |
|---|---:|---:|
| True Depth | 0.9270 | 0.8865 |
| Zero Depth | 0.9010 | 0.8563 |
| Cross-image Shuffled Depth | 0.9324 | 0.8865 |
| Spatial Shuffle Depth | 0.2920 | 0.0079 |

当前最值得关注的现象：

### 现象 1：去掉第 4 通道会掉点

True → Zero：

- Box：下降约 2.60 个百分点；
- Pose：下降约 3.02 个百分点。

说明第 4 通道不是完全被模型忽略。

### 现象 2：换成其他帧的 Depth 基本不掉点

True → Cross-image Shuffle：

- Pose 几乎完全不变。

这说明跨帧 Depth 替换对当前 test 的破坏力度不大。

### 现象 3：破坏 Depth 空间结构后模型几乎崩溃

True → Spatial Shuffle：

- Box mAP50-95：0.9270 → 0.2920
- Pose mAP50-95：0.8865 → 0.0079

说明已经训练好的 RGBD 模型对第 4 通道的空间组织非常敏感。

---

## 7. 原始 Depth 三帧一致性检查

为了判断 Cross-image Shuffle 为什么几乎不影响结果，随机抽取了 3 张原始 `.npy` 深度数据进行检查。

> 注意：这里检查的是原始 `uint16` Depth `.npy`，目的是分析采集过程中的深度变化；正式 RGBD 网络输入使用的是融合后的 4 通道图像，因此这部分是“采集数据侧分析”，不是直接的网络输入消融。

三张 Depth：

- shape：`(720, 1280)`
- dtype：`uint16`
- 非 0 有效深度比例约 86%～87%
- 存在 0 无效值以及 65535 附近的饱和值

### 7.1 两两比较

| 对比 | MAE | RMSE | Pearson r |
|---|---:|---:|---:|
| 0 vs 1 | 143.76 | 264.11 | 0.9031 |
| 0 vs 2 | 86.93 | 146.63 | 0.8802 |
| 1 vs 2 | 110.67 | 219.52 | 0.9218 |

说明：

> 三张 Depth 的整体场景高度相关，但并不完全相同。

### 7.2 水平平移检查

在 x 方向 ±300 px 搜索最佳水平位移：

| 对比 | 最佳 shift | shift 前 MAE | shift 后 MAE | shift 后 Pearson |
|---|---:|---:|---:|---:|
| 0 vs 1 | +10 px | 143.76 | 142.60 | 0.7063 |
| 0 vs 2 | +46 px | 86.93 | 82.88 | 0.5973 |
| 1 vs 2 | -2 px | 110.67 | 110.37 | 0.9282 |

MAE 改善幅度很小，因此不能认为这些帧只是简单的水平刚性平移。

### 7.3 当前判断

三张原始 Depth：

- 不是几乎完全一致；
- 也不能通过单纯水平平移解释；
- 但整体场景依然高度相关；
- 主体局部 Depth 结构存在真实变化。

因此 Cross-image Shuffle 中“换成另一张 Depth”虽然不是完全相同的数据，但仍可能保留大量类似的低频深度结构。

## 8. 到目前为止可以说什么

### 8.1 可以比较稳妥地说

#### 事实 1

当前 Hand 独立 test 上：

> RGBD 最终精度没有超过 RGB。

#### 事实 2

RGBD 模型并没有完全忽略第 4 通道。

依据：

> True Depth > Zero Depth。

#### 事实 3

RGBD 模型对第 4 通道中的空间组织高度敏感。

依据：

> Spatial Shuffle 后 Pose mAP50-95 从 0.8865 降到 0.0079。

---

## 9. 目前还不能直接说什么

当前还不能直接写：

> “Spatial Shuffle 后模型崩溃，因此已经证明模型学习到了真实三维人体几何。”

原因是 Spatial Shuffle 是一种非常强烈的输入破坏：

- 正确 Depth 几何结构被破坏；
- RGB 与 Depth 的配准关系被破坏；
- 原本连续平滑的 Depth 变成高频随机空间噪声；
- 这类输入可能严重偏离训练分布。

因此现阶段更严谨的表达应该是：

> RGBD 模型对第四通道及其空间组织具有显著敏感性。

至于这种敏感性中有多少可以归因于“有意义的深度几何信息”，仍需要继续拆解。

---

## 10. 当前实验最核心的矛盾

目前已经出现一个非常明确的现象：

> RGBD 模型明显依赖第四通道，但这种依赖没有在当前 Hand 12 张独立 test 上转化成优于 RGB 的最终 mAP。

可以简化为：

```text
RGBD vs RGB
→ RGBD 没赢

True Depth vs Zero Depth
→ 去掉 Depth 会下降

True Depth vs Spatial Shuffle
→ 破坏 Depth 空间结构后模型几乎崩溃
```

所以当前真正需要继续研究的问题已经从：

> “Depth 有没有用？”

逐渐收缩成：

> “为什么模型明显依赖 Depth，但这种信息没有转化成比 RGB 更好的泛化性能？”

---

## 11. 当前阶段暂不下最终论文结论

Hand test 只有 12 张，样本量很小，而且 RGB / RGBD 的 P、R、mAP50 都已经接近上限。

因此本报告只作为阶段性事实记录。

当前暂不：

- 为了让 RGBD 获胜而调参；
- 删除不理想实验结果；
- 把消融结果过度解释成三维几何已经被完全证明；
- 直接修改论文最终结论。

下一阶段应围绕以下问题逐项推演：

1. test 样本量是否过小；
2. Hand 场景是否本身过于简单，RGB 已接近性能天花板；
3. Depth 表示方式是否保留了足够有效的几何信息；
4. RGBD 第一层 4 通道初始化与后续训练是否真正适合当前任务；
5. 模型是否对 Depth 形成了依赖，但这种依赖反而影响了跨样本泛化；
6. 腹部、腿部实验是否呈现相同或不同规律；
7. 是否需要更合理的 Depth 扰动实验进一步区分“空间结构依赖”和“真实几何贡献”。

---

## 12. 当前阶段一句话总结

> **Hand 实验目前不能证明 RGBD 的最终精度优于 RGB，但消融实验已经表明：训练后的 RGBD 模型并未忽略第 4 通道，并且对该通道的空间组织具有非常强的敏感性。下一阶段需要解释这种 Depth 依赖为什么没有转化成更高的独立 test 泛化性能。**
