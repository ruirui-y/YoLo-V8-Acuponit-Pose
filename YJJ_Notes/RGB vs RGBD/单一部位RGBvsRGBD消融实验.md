# 方向一实验总结：单一部位 RGB vs RGBD 消融实验

## 1. 实验目的

验证深度通道（第4通道）对不同身体单一部位的穴位关键点检测是否有帮助，并对比深度通道在不同部位下的有效性差异。

## 2. 通用模型配置

| 参数       |        RGB 模型        |         RGBD 模型         |
| ---------- | :--------------------: | :-----------------------: |
| 骨架网络   |      YOLOv8n-Pose      |       YOLOv8n-Pose        |
| 输入通道   |        3（RGB）        |     4（RGB + Depth）      |
| 预训练权重 | 官方 `yolov8n-pose.pt` | 基于 RGB 训练好的权重转换 |
| 初始学习率 |         0.0005         |          0.0005           |
| 数据增强   |          一致          |           一致            |
| 训练轮数   |     70 轮（早停）      |      120 轮（跑满）       |

## 3. 实验 A：腹部（133 张，3 个关键点）

### 3.1 数据说明

| 集       |   比例   |    数量    |

| train    |   70%    |   93 张    |
| val      |   15%    |   20 张    |
| test     |   15%    |   20 张    |
| **合计** | **100%** | **133 张** |

### 3.2 训练配置

- **RGB 权重路径**: `runs/pose/133/train_pose_rgb_3ch/weights/best.pt`
- **RGBD 权重路径**: `runs/pose/133/train_pose_rgbd_4ch_133/weights/best.pt`
- **RGB YAML**: `datasets/acupoint_rgb.yaml`
- **RGBD YAML**: `datasets/acupoint.yaml`

### 3.3 训练过程（val 集指标）

| 实验 |   epochs   | Box mAP50 | Box mAP50-95 | Pose mAP50 | Pose mAP50-95 |
| ---- | :--------: | :-------: | :----------: | :--------: | :-----------: |
| RGB  | 70（早停） |   0.995   |    0.863     |   0.995    |     0.995     |

### 3.4 测试集成绩（最终）

| 指标             | RGB（3ch） | RGBD（4ch） |   差异    |
| ---------------- | :--------: | :---------: | :-------: |
| Box mAP50        |   0.9950   |   0.9950    |   持平    |

| Pose mAP50-95    |   0.9950   |   0.9950    |   持平    |

### 3.5 结论

深度通道在腹部单一部位上显著有效（Box mAP50-95 提升 **4.2%**）。

## 4. 实验 B：腿部（113 张，10 个关键点）

### 4.1 数据说明

| 集       |   比例   |    数量    |
| -------- | :------: | :--------: |
| train    |   70%    |   79 张    |
| val      |   15%    |   17 张    |
| test     |   15%    |   17 张    |
| **合计** | **100%** | **113 张** |

### 4.2 训练配置

- **RGB 权重路径**: `runs/pose/leg/train_pose_rgb_3ch/weights/best.pt`
- **RGBD 权重路径**: `runs/pose/leg/train_pose_rgbd_4ch/weights/best.pt`
- **RGB YAML**: `datasets/acupoint_leg_rgb.yaml`
- **RGBD YAML**: `datasets/acupoint_leg.yaml`

### 4.3 训练过程（val 集指标）

| 实验 | epochs | Box mAP50 | Box mAP50-95 | Pose mAP50 | Pose mAP50-95 |
| ---- | :----: | :-------: | :----------: | :--------: | :-----------: |
| RGB  |  120   |   0.995   |  **0.587**   |   0.995    |   **0.691**   |
| RGBD |  120   |   0.995   |  **0.505**   |   0.995    |   **0.667**   |

> ⚠️ 注意：vall 集上 RGB 反而比 RGBD 高约 8%，但 test 集上是 RGBD 更好，说明 val 集（17 张）采样偏差较大。

### 4.4 测试集成绩（最终）

| 指标             | RGB（3ch） | RGBD（4ch） |   差异    |
| ---------------- | :--------: | :---------: | :-------: |
| Box mAP50        |   0.9950   |   0.9950    |   持平    |
| **Box mAP50-95** | **0.6219** | **0.6503**  | **+4.6%** |
| Pose mAP50       |   0.9950   |   0.9950    |   持平    |
| Pose mAP50-95    |   0.7462   | **0.7814**  | **+4.7%** |

### 4.5 结论

深度通道在腿部单一部位上也显著有效（Box mAP50-95 提升 **4.6%**），与腹部实验结果一致。

### 4.6 踩坑记录

|  #   | 问题                                                      | 原因                                                         | 解决方法                                                     |
| :--: | --------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
|  1   | **标签边框全为 0**                                        | 打标签时只画了关键点（穴位），没有画大框，导致 `cx=0, cy=0, w=0, h=0` | 编写 `rebuild_leg_boxes_from_keypoints.py`，根据关键点坐标范围自动计算最小包围框并放大 20% |
|  2   | **yaml 配置错误**                                         | 腿部的标签是 10 个关键点（非腹部 3 点），但 yaml 中 `kpt_shape` 未更新 | 创建专用的腿部 yaml，`kpt_shape: [10, 3]`                    |
|  3   | **RGB 模型用了含有 `rgbd:true` 的 yaml 导致通道数不匹配** | 之前腹部只有一个 yaml，但腿部需要区分 RGB 和 RGBD 版本       | 分别创建 `acupoint_leg.yaml`（rgbd:true, channels:4）和 `acupoint_leg_rgb.yaml`（rgbd:false, channels:3） |
|  4   | **标签缓存冲突**                                          | 修改 yaml 后旧的 `.cache` 缓存未清理，导致训练时加载了旧的标签信息 | 每次修改 yaml 或标签后，删除 `labels/*.cache`                |
|  5   | **标签关键点数量不一致**                                  | 腿部 381 张图片的关键点数量不统一（3~13 个不等），混杂在一起训练会导致错误 | 先用 `group_leg_labels_by_keypoint_count.py` 统计并按关键点数分类到 `point_N` 目录，选数据量最多的 `point_10`（113 张）进行实验 |

| :------------: | :------: | :----: | ------------------------------------------------------------ | :----------: | :-----------: | :-------: |
|    **腹部**    |    3     | 133 张 | `runs/pose/133/train_pose_rgb_3ch` / `train_pose_rgbd_4ch_133` |    0.8835    |  **0.9251**   | **+4.2%** |
| **腹部** (val) |    3     | 133 张 | 同上                                                         |    0.863     |   **0.865**   |   +0.2%   |

### 深度通道有效？✅ 是

两个单一部位在 **test 集**上的深度通道提升幅度高度一致（+4.2% / +4.6%），结论可靠。

## 7. 综合结论

### 7.1 核心发现

|  #   | 发现                             | 说明                                                         |
| :--: | -------------------------------- | ------------------------------------------------------------ |
|  1   | **同质数据下深度通道稳定有效**   | 腹部（+4.2%）和腿部（+4.6%）的提升幅度高度一致，说明深度通道在单一部位场景下具有稳定约 4-5% 的 Box mAP50-95 提升 |
|  2   | **多部位混合时深度通道反而恶化** | 580 张混合数据集下 RGBD 反而比 RGB 低 1.8-2.7%，说明深度特征在不同部位之间不可直接迁移 |
|  3   | **初始化方式至关重要**           | 用训练好的 RGB 权重初始化 RGBD 比用官方通用权重，性能提升 6.4% |
|  4   | **深度通道的适用边界**           | 同质数据（单一部位）→ 深度有效；异质数据（多部位混合）→ 深度反而增加过拟合风险 |
