## 方向一实验总结：RGB vs RGBD 消融实验

### 1. 实验目的

验证深度通道（第4通道）对腹部穴位关键点检测是否有帮助，并探索最优的 RGBD 训练策略。

### 2. 数据说明

| 阶段                   |      数据量      | 内容                           |
| ---------------------- | :--------------: | ------------------------------ |
| 第一阶段（已废弃）     |      133 张      | 仅腹部，单一体位               |
| **第二阶段（最终版）** |    **580 张**    | 腹部 + 腿部 + 手部，多部位混合 |
| 训练/验证/测试         | 406 / 87 / 87 张 | 70% / 15% / 15%                |

### 3. 模型配置

| 参数       |        RGB 模型        |      RGBD 模型（最终版）      |
| ---------- | :--------------------: | :---------------------------: |
| 骨架网络   |      YOLOv8n-Pose      |         YOLOv8n-Pose          |
| 输入通道   |        3（RGB）        |       4（RGB + Depth）        |
| 预训练权重 | 官方 `yolov8n-pose.pt` | **基于 RGB 训练好的权重转换** |
| 初始学习率 |         0.0005         |            0.0005             |
| 早停       |   无（跑满 120 轮）    |   patience=20（31 轮早停）    |
| 数据增强   |          一致          |             一致              |

### 4. 训练过程对比

|    实验     |     预训练来源     |    lr    | patience | 实际轮数 | Box mAP50-95 |
| :---------: | :----------------: | :------: | :------: | :------: | :----------: |
| RGB（基准） |      官方权重      |   5e-4   |    —     |   120    |  **0.8804**  |
|   RGBD v1   |      官方权重      |   5e-4   |    20    |    84    |    0.7986    |
|   RGBD v2   |      官方权重      |  2.5e-4  |    40    |    76    |    0.7506    |
| **RGBD v3** | **RGB 训练后权重** | **5e-4** |  **20**  |  **31**  |  **0.8625**  |

### 5. 测试集最终成绩

| 指标          | RGB（3通道） | RGBD（4通道，最终版） |   差异    |
| ------------- | :----------: | :-------------------: | :-------: |
| Box mAP50     |  **0.9398**  |        0.9376         |   -0.2%   |
| Box mAP50-95  |  **0.8804**  |        0.8625         | **-1.8%** |
| Pose mAP50    |  **0.9398**  |        0.9376         |   -0.2%   |
| Pose mAP50-95 |  **0.9398**  |        0.9376         |   -0.2%   |

### 6. 关键发现

|  #   | 发现                   | 说明                                                         |
| :--: | ---------------------- | ------------------------------------------------------------ |
|  1   | **初始化方式至关重要** | 用训练好的 RGB 权重初始化 RGBD（v3）比用官方权重（v1/v2），Box mAP50-95 提升 **6.4%**（0.7986 → 0.8625） |
|  2   | **学习率影响较小**     | 同样是官方权重起步，lr=5e-4（v1）vs lr=2.5e-4（v2），前者反而更好 |
|  3   | **最终差距仅 1.8%**    | 经过优化后的 RGBD 与 RGB 性能基本相当，深度通道没有带来负收益 |

### 7. 经验教训

- **4 通道模型的训练起点很关键**：用同分布数据训练好的 3 通道权重做初始化，比用通用 ImageNet 权重效果好得多
- 多部位混合训练下，深度通道的异质性导致模型更容易过拟合
- 同质数据（单一腹部）下 RGBD 可能有更明显的优势
- 论文中可以分析深度通道的**适用边界**，并强调**初始化策略对多通道模型的重要性**
